# État du MVP

## Inclus dans ce starter
- Homepage responsive avec les sections principales du tunnel de référence
- Identité visuelle Mon Histoire Chantée
- Tunnel `/composer` en 6 étapes avec sauvegarde locale
- Enregistrement des questionnaires dans Cloudflare D1
- Formules Essentielle, Premium et option Express
- Création du panier et redirection vers Shopify Checkout
- Administration `/admin` pour les textes, couleurs et médias principaux
- Stockage des médias personnalisés dans Cloudflare R2

## Prochaine étape utilisateur
1. Importer tous les fichiers dans le dépôt GitHub `mafthebuilder/mon-histoire-chantee`.
2. Connecter le dépôt à Cloudflare Workers.
3. Ajouter les secrets Shopify et le token administrateur.
4. Lancer le premier déploiement de test.
